# SadBarz

Calisthenics app and personal coach: build routines, run them with built-in timers (EMOM, EM2M, Tabata, intervals), log every set, and let the coach make the next session harder as you get stronger.

- Web prototype first, then iPhone and Android from the same code (Expo / React Native).
- Spanish first, with a language switch.

Status: planning. Code coming soon.
